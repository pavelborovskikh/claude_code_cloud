# System Design Docs

Plain-English system design documents for three projects. Each doc covers:

1. **System design** — a diagram plus a short explanation of every element.
2. **What went wrong and how it was fixed** — lessons learned from the build history.
3. **Evaluation elements and metrics** — how the project is assessed and what is measured.
